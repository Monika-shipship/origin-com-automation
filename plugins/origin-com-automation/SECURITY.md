# Security Policy

## Reporting a vulnerability

Please report security issues through GitHub private vulnerability reporting
when it is enabled for this repository. Do not open a public issue containing
credentials, proprietary Origin projects, experimental data, or personal paths.

## Scope

Security-sensitive areas include COM instance ownership, source-file overwrite
protection, process cleanup, LabTalk execution, path validation, and log
redaction. Reports should include the plugin version, Windows and Origin
versions, the failing tool, and a minimal reproduction that contains no
sensitive worksheet data.
