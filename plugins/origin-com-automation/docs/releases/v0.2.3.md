# Origin COM Automation v0.2.3

0.2.3 is a presentation and distribution release. The Origin automation behavior remains the lean
0.2.2 path: exactly 45 tools, linked imports by default, editable Origin `F(x)` formulas, native
Analysis Operations where verified, protected source projects, bounded readback, and owned-session
shutdown.

## Added

- Plot Workspace plugin icon in vector, 512 px, and small composer forms.
- Clear user-first English and Simplified Chinese README files.
- Ready-to-use request templates and plotting prompts for users who do not need to know COM or MCP.
- Focused user guide, complete 45-tool reference, and implementation architecture reference.
- Clickable badges for the stable release, release gates, verified environment, Codex plugin, and
  license.
- A lightweight Git marketplace branch for direct Codex installation and updates.

## Unchanged

- No new MCP tools, analysis methods, task planner, validation stage, or scientific default.
- No change to the 0.2.2 execution path or schema digest.
- No merge of the rejected 0.3.0, 0.3.1, or 0.4.0 workflow experiments.

## Validation

See [0.2.3 Validation](../VALIDATION-0.2.3.md) for exact automated, live Origin, installation, and
release-asset evidence.

## Install

```powershell
codex plugin marketplace add Dawn-zxj/origin-com-automation --ref marketplace
codex plugin add origin-com-automation@origin-automation-marketplace
```

Start a new Codex task after installation so the new manifest, icon, Skill, and MCP tool surface are
loaded together.
