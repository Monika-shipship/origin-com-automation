# Origin COM Automation v0.2.2

v0.2.2 is a maintenance release built on the lean 0.2.1 execution path. It improves internal
maintainability and runtime isolation without adding tools, workflow stages, or user-facing task
steps.

## Highlights

- Preserves exactly 45 MCP tools and the complete 0.2.1 schema contract.
- Keeps linked imports, editable Origin `F(x)` formulas, and native Analysis Operations.
- Keeps source-project protection, owned-session shutdown, timeout recovery, and bounded readback.
- Adds a version-scoped, non-editable Python runtime with a bootstrap lock.
- Splits large internal MCP and COM support modules without changing public behavior.

## Validation

- `276 passed, 8 skipped` in the complete Python test suite.
- Ruff and mypy passed.
- Wheel, source distribution, dependency check, plugin validator, Skill validator, distribution
  validator, and release audit passed.
- Installed MCP stdio exposed 45 tools with the preserved schema digest and passed health check.
- Real Origin `10.1.0.178` tests covered linked import, editable formulas, native fit operations,
  graph export, project save/reopen, pixel QA, and owned shutdown.

## Installation

Download and extract the complete plugin ZIP, or clone the repository, then run
`scripts/bootstrap.ps1`. The wheel and source distribution are also available for Python package
use. Origin must be installed and expose a compatible registered COM server. Start a new Codex
task after installing or refreshing the plugin.

The project is independent and is not affiliated with or endorsed by OriginLab. Back up important
projects and source data, and review and validate outputs before scientific or engineering use.
